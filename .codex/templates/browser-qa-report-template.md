## 판정 기준

- Critical: 잘못된 범위 데이터의 정상 표시, 숨겨진 데이터 불일치, 핵심 서비스 전체 중단, 민감정보 노출, 매우 높은 잘못된 품질 판단 위험
- High: 주요 기능 불가, 반복되는 잘못된 결과·화면 중단, stale data 표시, 실사용 불가 수준의 대량 병목
- Medium: 조건부 오류, 부족한 오류 안내, 우회 가능한 문제, 일정 규모 이상 체감 저하
- Low: 경미한 UI·접근성·로그·경고
- 신뢰도 높음: 반복 재현과 직접 증거가 일치함
- 신뢰도 중간: 제한된 재현 또는 강한 간접 근거가 있음
- 신뢰도 낮음: 단일 관찰, 환경 제약 또는 추가 확인이 필요함
