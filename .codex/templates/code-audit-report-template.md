## 판정 기준

- Critical: 잘못된 범위 데이터의 정상 표시, 숨겨진 데이터 불일치, 핵심 서비스 전체 중단, 민감정보 노출, 매우 높은 잘못된 품질 판단 위험
- High: 주요 기능 불가, 반복되는 잘못된 결과, stale data 표시, 특정 화면·필터의 정합성 오류
- Medium: 조건부 오류, 유지보수 위험이 큰 핵심 코드, 우회 가능한 문제
- Low: 즉시 장애로 이어지지 않는 코드 정리·경고·제한 위험
- 신뢰도 높음: 결정적 코드 경로 또는 반복 재현과 직접 증거가 있음
- 신뢰도 중간: 도달 가능한 코드 위험과 일부 재현·테스트 근거가 있음
- 신뢰도 낮음: 외부 계약·요구사항·도달 조건의 추가 확인이 필요함
