## 판정 기준

- Critical: 핵심 서비스 전체 사용 불가, 숨겨진 데이터 불일치 또는 민감정보 노출과 결합된 병목
- High: 주요 흐름 불가, 반복 중단, 대량 데이터에서 실사용이 어려운 측정 병목
- Medium: 일정 규모 이상에서 체감되는 저하 또는 우회 가능한 성능 문제
- Low: 즉시 장애로 이어지지 않는 경미한 비용
- 신뢰도 높음: 통제된 반복 측정과 trace/profile 근거가 일치함
- 신뢰도 중간: 반복 측정은 있으나 환경 변수가 일부 통제되지 않음
- 신뢰도 낮음: 표본이 적거나 도구·환경 제한으로 추가 측정이 필요함
