## 1. 서비스 개요와 접속

사내에서 안내받은 주소로 접속합니다. SSO 로그인 안내가 나오면 로그인하고, 접근 권한이 없으면 마스터 사용자에게 권한을 요청하세요. 상단 사용자 메뉴에서 로그인 정보와 권한을 확인하고 로그아웃할 수 있습니다.

메인 화면에서 원하는 카드를 선택합니다. 각 화면의 **SPIDER 메인** 또는 **Main**으로 돌아올 수 있습니다.

| 메뉴 | 하는 일 |
| --- | --- |
| 설비별 SPEC내 이상감지 | 설비·센서별 추이 확인 |
| 동일성 / 공통부 / 공통부 동일성 이상감지 | 조건별 분석 이미지와 비교 결과 확인 |
| Mailing Report 및 My EQP 등록 | 메일 수신 조건, 수신인 그룹, 모니터링 설비 등록 |
| 메일보내기 이력 및 이력저장 게시판 | 차트 메일·저장 이력 확인과 업무 상태 관리 |
| VOE 게시판 | 문의·기능 요청 작성과 답변 확인 |
| Defect / L1 / L3 SPIDER | 해당 서비스로 이동 |

공지사항은 화면의 알림 버튼에서 확인합니다. 공지 관리 권한이 있는 사용자는 메인의 **공지사항 관리**에서 등록·완료 처리할 수 있습니다. 마스터는 **권한 관리**에서 사용자·부서별 접근 권한을 관리합니다.

## 2. 메인 화면과 라인별 대시보드

1. 메인 아래 **라인별 이상 현황 Dashboard**에서 라인을 선택하고 **조회**를 누릅니다.
2. 모니터링 센서 수, 전체·등급별 이상 건수, 전일 대비와 추이를 확인합니다.
3. 라인별 상세 현황의 **상세**를 누르면 해당 라인의 설비별 이상감지로 이동합니다.

## 3. 필터 공통 사용법

- 왼쪽부터 차례로 선택합니다. 앞 조건을 바꾸면 뒤 조건도 다시 선택하세요.
- 마지막 필터를 선택하면 자동 조회됩니다. `ALL`은 현재 조건의 전체 대상입니다.
- 검색창으로 항목을 찾고, 필터 아래 경계를 드래그해 목록 높이를 조절합니다.
- 결과가 많으면 페이지 버튼으로 나누어 확인합니다.

## 4. 설비별 SPEC내 이상감지

**Line Name → SDWT → Sensor Grade → STEP → eqp_ch → sensor → ch_step** 순서로 선택합니다. Grade는 복수 선택할 수 있습니다. sensor가 `ALL`이면 ch_step도 `ALL`로 조회합니다.

- 차트의 점에 마우스를 올려 측정값을 확인합니다.
- **3일치 동일성 차트 같이 보기**를 켜면 대표 차트 옆에 최근 72시간 비교 차트가 표시됩니다.
- **ch_step 전체보기 / ch_step 모아보기**로 전체 차트와 대표 차트를 전환합니다.
- 처음에는 **CRITICAL**이 선택됩니다. 차트 위 **CRITICAL / WARNING** 버튼으로 결과를 좁히고, 같은 버튼을 다시 누르면 전체로 돌아갑니다.
- 필터와 차트의 이상 건수는 **ch_step 모아보기** 기준입니다. 차트의 건수에는 현재 CRITICAL / WARNING 선택도 반영됩니다.

| 버튼 | 사용 방법 |
| --- | --- |
| SKIP | 현재 건을 72시간 동안 일반 결과에서 제외 |
| EQP ALL SKIP | 같은 EQP·sensor의 모든 ch_step을 제외 |
| SKIP해제 | SDWT의 `SKIP LIST`에서 제외 해제 |
| 동일성 차트 | 동일 조건의 설비 데이터 비교 |
| 변경점이력 / 이력저장 | 변경점 확인 / 현재 결과 기록 |
| 메일보내기 | 차트 이미지와 코멘트를 메일로 전송 |

## 5. Mailing Report 및 My EQP 등록

필요한 영역을 **펼치기**로 열고, 그 영역의 저장 버튼을 누릅니다.

| 영역 | 등록 순서 |
| --- | --- |
| Mailing Report 수신인 등록 | Line·SDWT·Grade 선택 → 수신인 Knox ID 입력 후 Enter → **Mailing Report 저장** |
| Chart Mailing 수신인 등록 | 그룹 이름·수신인 Knox ID 입력 → **Chart Mailing 저장** |
| My EQP 등록 | Line Name·SDWT·PRC Group·EQP 선택 → 모니터링 기간·열람 및 메일수신인 입력 → **My EQP 저장** |

Mailing Report의 Grade는 A·B·D·M·N 중 1개 이상 복수 선택합니다. 처음에는 전체가 선택되어 있으며, 필요 없는 Grade를 눌러 해제할 수 있습니다. 같은 수신인에게 추가로 저장하면 선택한 SDWT·Grade 조합만 추가됩니다.
등록 목록의 **Grade 삭제**는 해당 행의 SDWT·Grade 한 건만 삭제하고, 다른 조건은 유지합니다. **Line 삭제**는 해당 Line 조건 전체를 삭제합니다. 삭제 전 확인창에서 대상 SDWT와 Grade를 확인하세요.

My EQP 수신인은 Knox ID 입력 후 Enter로 추가합니다. 등록한 설비는 설비별 이상감지의 **SDWT → MY EQP**에서 조회하며, STEP의 `ALL`로 여러 STEP을 함께 볼 수 있습니다. 만료된 조건은 조회 대상에서 제외되고, 본인이 등록한 조건만 삭제할 수 있습니다.

## 6. 동일성·공통부 이상감지

### 6.1 동일성 이상감지

**Line Name → SDWT → STEP → Sensor → ch_step**을 선택해 분석 이미지를 확인합니다.

### 6.2 공통부 이상감지

**Line Name → SDWT → prc_group → eqp → sensor**를 선택합니다. 카드의 **동일성 차트**로 설비를 비교하고, **SKIP / SKIP해제**로 제외 대상을 관리합니다.

### 6.3 공통부 동일성 이상감지

**Line Name → SDWT → EQP_MODEL → Sensor → ch_step**을 선택해 모델별 분석 이미지를 확인합니다.

동일성·공통부 동일성에서 Sensor가 `ALL`이면 ch_step도 `ALL`입니다. 각 화면의 **이력저장**은 해당 카드의 결과를 기록합니다.

## 7. 메일과 메일보내기 이력 및 이력저장 게시판

### 차트 메일 보내기

1. 설비별·동일성·공통부 이상감지 카드에서 **메일보내기**를 누릅니다.
2. 저장된 수신인 그룹을 선택하거나 Knox ID를 직접 입력합니다.
3. 제목·코멘트·최종 수신인과 차트 미리보기를 확인합니다. 이미지는 확대 상태가 아닌 **전체 범위**로 전송됩니다.
4. **보내기**를 누르고 결과를 확인합니다.

### 차트 이력저장

각 이상감지 App의 **이력저장**을 누르면 메일과 같은 양식으로 현재 차트의 전체 범위 이미지를 게시판에 저장합니다. 메일은 발송하지 않습니다.
발신자·수신인은 저장한 본인의 Knox ID이며, 제목에는 **이력을 저장했습니다**, 본문 코멘트에는 **이력을 저장했습니다**가 들어갑니다.
등록이 끝나면 **메일보내기 이력 및 이력저장 게시판 등록 완료** 팝업이 표시됩니다. 게시판에서 **이력저장 · 메일 미발송**으로 구분할 수 있습니다.

### 발송·저장 이력 확인과 상태 변경

**메일보내기 이력 및 이력저장 게시판**에서 라인·SDWT·업무 상태로 필터링하거나 제목·발신자·차트 정보로 검색합니다. 제목을 누르면 수신인, 코멘트, 등록 당시 이미지와 현재 차트 링크를 볼 수 있습니다.

로그인 사용자는 **완료 처리 / 진행중으로 변경**을 할 수 있고, 처리 코멘트를 남길 수 있습니다. 상태 변경 이력이 기록되며 추가 메일은 발송되지 않습니다. 메일 상태가 **결과 확인 필요**이면 재발송 전에 수신 여부를 확인하세요.

마스터 권한 사용자에게는 게시글 상세 화면에 **게시글 삭제** 버튼이 표시됩니다. 삭제 확인 후 글·이미지·수신인·상태 변경 이력이 제거되며 복구할 수 없습니다. 이미 발송된 메일은 회수되지 않습니다. 일반 사용자는 삭제할 수 없습니다.

### Mailing Report 확인

수신한 Report의 **LINK**로 해당 조건의 설비별 이상감지 화면을 엽니다. My EQP 링크는 **MY EQP** 조건으로 연결됩니다. 정기 메일 수신이 되지 않으면 등록 조건을 확인한 뒤 운영 담당자에게 문의하세요.

## 8. VOE 게시판

1. **질문 작성**을 누릅니다.
2. 카테고리 **L0 SPIDER / L1 SPIDER / L3 SPIDER / Defect SPIDER / 기타**를 선택합니다.
3. 제목과 본문을 입력하고 **질문 등록**을 누릅니다. 본문에는 글씨 크기·표·이미지·링크를 사용할 수 있습니다.
4. 목록에서 글을 열고 **답변 작성 → 답변 등록**으로 대화를 이어갑니다.

- 목록과 상세 화면에 카테고리가 표시됩니다. 기본값과 기존 미분류 글은 **기타**입니다.
- **전체 / 답변 대기 / 답변 중 / 답변 완료**로 목록을 좁힐 수 있습니다.
- 작성자는 자신의 질문·답변을 수정할 수 있습니다. 카테고리도 질문 수정에서 변경합니다. 질문 삭제는 답변이 없을 때 가능합니다.
- 마스터는 상태 변경, 최종 답변 지정, 삭제 글 복구와 변경 이력 확인을 할 수 있습니다.
- 다른 사람이 내 질문에 답변하거나 상태·최종 답변을 변경하면 **VOE 상단 알림**에서 확인합니다. **이메일은 발송되지 않습니다.**

## 9. 문제 해결과 주의사항

| 상황 | 확인할 내용 |
| --- | --- |
| 로그인·접근 오류 | 다시 로그인하거나 마스터에게 접근 권한 요청 |
| 선택 항목이나 결과가 없음 | 앞 단계 조건, `ALL`, MY EQP 유효기간 확인 |
| 이미지·차트 로딩 실패 | **다시 조회** 또는 새로고침 |
| 저장·메일 발송 실패 | 화면 안내 확인. 메일은 수신 여부 확인 후 재시도 |
| 사진이 큰 게시글 저장 실패 | 이미지 크기를 줄인 뒤 다시 등록 |

계속 실패하면 **메뉴, 발생 시각, 선택 조건, 오류 메시지·문의 코드**를 운영 담당자에게 전달하세요. 비밀번호 등 비밀정보는 포함하지 마세요. 저장·삭제·메일 전송 전에는 대상과 수신인을 확인하세요.
